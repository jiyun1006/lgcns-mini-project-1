# 게시판 화면 기본 구조

화면 설계안을 기준으로 게시판 UI와 페이지 구조를 구현했습니다. 현재는 DB 연결 없이 샘플 데이터로 동작합니다.

## 경로

| 경로 | 화면 |
|---|---|
| `/posts` | 트렌딩 카드, 게시글 목록, 검색, 카테고리 필터, 정렬 |
| `/posts/1` | 게시글 상세, 프롬프트 복사, 좋아요, 댓글·답글 영역 |
| `/posts/new` | 게시글 작성 |
| `/posts/1/edit` | 기존 샘플 데이터가 입력된 게시글 수정 |

## 파일 구성

| 경로 | 역할 |
|---|---|
| `app/posts/` | 페이지 라우팅, 게시판 전용 레이아웃 및 스타일 |
| `components/board/` | 헤더, 목록, 상세, 공용 작성·수정 폼 |
| `types/board.ts` | 게시글·댓글 등 화면에서 사용하는 타입 |
| `lib/board/mock-data.ts` | 샘플 게시글·댓글 데이터 |

## 실행 방법

프로젝트 폴더에서 아래 명령어를 실행합니다.

```bash
npm ci
npm run dev -- --webpack
```

실행 후 [게시판 페이지](http://localhost:3000/posts)에 접속합니다.

기존 홈 화면과 Prisma 스키마는 변경하지 않았습니다.

## 구현 내용

- 게시판 목록·상세·작성·수정 화면 구성
- 인기 게시글 카드 표시
- 제목·본문·태그 검색
- 카테고리별 필터
- 최신순·조회순·좋아요순 정렬
- 프롬프트 복사
- 좋아요 UI 토글
- 태그 추가·삭제 및 최대 5개 제한
- 작성·수정 폼 필수 입력 검증
- 로딩 화면 및 존재하지 않는 게시글 안내

## 현재 동작 범위

샘플 데이터를 기준으로 화면과 기본 동작을 확인할 수 있습니다.

- 좋아요는 화면 상태에만 반영되며, 새로고침하면 초기화됩니다.
- 작성·수정 폼을 제출하면 안내 문구가 표시되며, 데이터는 저장되지 않습니다.
- 수정 화면 링크는 화면 확인을 위해 모두에게 표시됩니다.
- 게시글 삭제와 댓글·답글 등록은 연결 전 상태입니다.
- 프롬프트 사용하기 버튼은 AI 채팅 연결 예정 안내를 표시합니다.
- AI 답변 예시는 일반 텍스트로 표시합니다.

## 후속 개발 사항

1. **게시글 데이터 연결**  
   Prisma 기반 Service와 Server Action을 구현하고 샘플 데이터를 DB 조회 결과로 교체합니다.

2. **데이터 모델 확장**  
   게시글의 카테고리, 프롬프트, 답변·후기, 태그 필드와 댓글의 답글 관계를 팀 협의 후 추가합니다.

3. **인증 및 권한 검증**  
   NextAuth 세션으로 작성자를 식별하고, 서버에서 게시글·댓글의 수정·삭제 권한을 검증합니다.

4. **데이터 변경 기능 구현**  
   게시글 등록·수정·삭제, 좋아요, 댓글·답글 기능에 서버 검증과 오류 처리를 연결합니다.

5. **AI 채팅 연동**  
   채팅 담당자와 프롬프트 전달 방식을 정하고, 새 채팅 입력창에 공유 프롬프트를 전달하도록 연결합니다.

6. **목록 기능 확장**  
   실제 데이터 조회를 기준으로 기간별 인기글 집계와 페이지네이션을 추가합니다.

7. **마크다운 표시 지원**  
   마크다운 렌더러를 선정하고 사용자 입력을 안전하게 표시하도록 처리합니다.
